## Threshold Decision Options

1. Disable or collapse the medium tier until it has positive economics.

   This is the most conservative behavior if `NUDGE_PREPAY` remains loss-making. It requires an explicit plan deviation because the router is designed around three tiers.

2. Adjust threshold constraints so the optimizer can avoid uneconomic medium-tier assignments.

   If the plan permits this, allow `t_high` to approach `t_low` or add a minimum economic constraint during grid search.

3. Keep the current thresholds only as an experimental checkpoint artifact.

   If this path is chosen, do not wire them into Day 06 production routing without a visible warning and Day 10 sensitivity reporting.
